# Workforce Management System

React front-end for a workforce management landing page based on the Figma mockup for IN4MATX 124 Assignment 2.

## What it includes

- React components for the header, hero, features, statistics, contact form, login page, and footer
- React Router navigation between the home page and login page
- Component state for selected features, contact form submission, and login form feedback
- Responsive CSS for desktop, tablet, and mobile layouts
- Accessible labels, semantic landmarks, keyboard-focus styles, and live status messages

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Build

```bash
npm run build
```
